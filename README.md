# BookStore
A bookstore application to manage books, users, and shopping carts. This application is built using FastAPI, SQLALchemy, and PostgreSQL.
It provides RESTful APIs for managing books, users, and shopping carts.

<b>The app is structured as follows:</b></br>
<b>auth:</b> handle user authentication and authorization</br>
<b>core:</b> contains the core configuration and setting for the app</br>
<b>database:</b> contains the db configuration</br>
<b>dependencies:</b> contains dependencies the app</br>
<b>models:</b> contains the model for the db tables</br>
<b>routes:</b> contains the API routes for the app</br>
<b>schemas:</b> contains the pydantic schemas for the app</br>
<b>services:</b> contains the business logic for the app</br>

<b>The tests are structured as follows:</b></br>
api: contains the test for the API routes
services: contains the test for the services

<b>Dependencies:</b></br>
are contained in the requirements.txt file
